## نبذة عن المشروع

**CupAI** هي منصة تحليل مباريات كأس العالم **قائمة تمامًا على البيانات + ذكاء اصطناعي خاص بالمستخدم** مخصصة لعشاق كرة القدم حول العالم. لا تتضمن المنصة قدرات توليد ذكاء اصطناعي مدمجة؛ بل تموضع نفسها كـ "مزود شامل لبيانات المباريات + حامل أدوات التحليل". توفر بيانات أساسية كاملة وفي الوقت الفعلي ودقيقة للمباريات، بينما يقوم المستخدمون بتكوين نماذج لغوية كبيرة خاصة بهم، وتخصيص الأوامر (Prompts)، وضبط أوزان عوامل المباريات، وإجراء تحليلات معمقة بشكل مستقل.

### المميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🔑 **نماذج لغوية خاصة بالمستخدم** | يدعم Doubao وDeepSeek وGPT وQwen والمزيد — يوفر المستخدمون مفاتيح API الخاصة بهم، تكلفة صفرية للذكاء الاصطناعي على المنصة |
| 🧩 **سوق أوامر مخصصة** | إنشاء ومشاركة وإعادة استخدام قوالب الأوامر — بناء أفضل مكتبة لقوالب تحليل كرة القدم |
| ⚖️ **أوزان عوامل قابلة للتعديل** | 8 فئات من عوامل التحليل مع تخصيص حر من 0%-100% — ابنِ نموذج التحليل الخاص بك |
| 🤖 **استدلال آلي بواسطة وكيل الذكاء الاصطناعي** | مدعوم بـ 5 خوارزميات خاصة — تحليل مباريات مؤتمت بالكامل بدون تدخل يدوي |
| 🌍 **تدويل بـ 8 لغات** | zh-CN / en-US / es-ES / fr-FR / pt-BR / ar-SA / ja-JP / ko-KR — يغطي الدول الرئيسية المشاركة في كأس العالم |
| 🛡️ **تحليل رياضي متوافق تمامًا** | بدون قمار، بدون رهانات — مراجعة تكتيكية بحتة واستنتاج قائم على البيانات |

## التقنيات المستخدمة

| الطبقة | التقنية | الغرض |
|--------|---------|-------|
| 🖥️ **الواجهة الأمامية** | Vue 3 + Vite + Element Plus | واجهة متجاوبة، لوحات بيانات، تصنيفات |
| ⚡ **الوقت الفعلي** | Socket.io | نتائج مباشرة، إشعارات فورية |
| 📊 **الرسوم البيانية** | ECharts | اتجاهات الدقة، توزيع الأوزان، درجات المشاعر |
| 🌐 **التدويل** | vue-i18n (8 لغات) | متعدد اللغات، مناطق زمنية متعددة، تكيف عالمي |
| 🔧 **الواجهة الخلفية** | NestJS + TypeORM (TypeScript) | واجهات برمجة تطبيقات معيارية، ترحيل الذكاء الاصطناعي، معالجة البيانات |
| 🗄️ **قاعدة البيانات** | MySQL 8.0 | بيانات منظمة: مستخدمون، قوالب، تقارير، تصنيفات |
| ⚡ **التخزين المؤقت** | Redis | تخزين مؤقت في الوقت الفعلي، تحديد معدل واجهة برمجة التطبيقات، بيانات ساخنة |
| ⏰ **الجدولة** | node-schedule | مسح تلقائي للوكيل، إنشاء التقارير، فحص البيانات |
| 🐳 **النشر** | Docker + Docker Compose + Nginx | نشر بنقرة واحدة، وكيل عكسي، SSL |

### 5 خوارزميات خاصة

| الخوارزمية | الوظيفة |
|------------|---------|
| 📐 التطبيع الديناميكي للأوزان | تطبيع تلقائي للفاصلة العائمة بعد أوزان يحددها المستخدم — يمنع عدم التوازن في التخصيص |
| 🎯 الضبط التكيفي حسب السيناريو | يتعرف الوكيل تلقائيًا على مستوى المباراة / سمات الفريق / خصائص المواجهة — يعدل الأوزان ديناميكيًا |
| 🔇 إزالة الضوضاء متعددة الأبعاد والموثوقية | يصفية البيانات غير الصالحة، وتصنيف مستويات الثقة، وإزالة القيم المتطرفة |
| 📊 تحديد المشاعر الاجتماعية | تسجيل قطبية المشاعر (-10~10)، مؤشر الضغط العام، تقييم التركيز |
| ⚖️ تصحيح التوازن متعدد العوامل | توازن متبادل وتصحيح تكميلي متعدد العوامل — يتجنب التضليل ببيانات مفردة |

## البدء السريع

### المتطلبات المسبقة

- **Node.js** >= 18.x
- **MySQL** >= 8.0
- **Redis** >= 6.x
- **Docker** & **Docker Compose** (اختياري)

### نشر Docker بنقرة واحدة

```bash
git clone https://github.com/XieWxx/cupai.git
cd cupai
cp .env.example .env
docker compose up -d
```

زيارة في المتصفح: `http://localhost:3000`

### التطوير المحلي

```bash
pnpm install

# بدء الواجهة الخلفية
cd apps/server && pnpm dev

# بدء الواجهة الأمامية
cd apps/web && pnpm dev
```

## هيكل المشروع

```
cupai/
├── apps/
│   ├── web/                   # الواجهة الأمامية (Vue 3 + Vite)
│   │   └── src/
│   │       ├── views/         # الصفحات (8 مشاهدات رئيسية)
│   │       ├── stores/        # إدارة حالة Pinia
│   │       ├── locales/       # تدويل بـ 8 لغات
│   │       ├── api/           # طبقة طلبات API + WebSocket
│   │       └── components/    # مكونات مشتركة
│   └── server/                # الواجهة الخلفية (NestJS)
│       └── src/
│           ├── modules/       # 7 وحدات أعمال
│           │   ├── user/      # وحدة المستخدمين
│           │   ├── ai/        # وحدة ترحيل الذكاء الاصطناعي
│           │   ├── match/     # بيانات المباريات + الترتيبات
│           │   ├── prompt/    # سوق الأوامر + التحقق
│           │   ├── ranking/   # التصنيفات
│           │   ├── agent/     # الوكيل + التفاعل + التحليل
│           │   └── risk/      # إدارة المخاطر + الكلمات الحساسة
│           ├── config/        # إعدادات Redis + تحديد المعدل
│           └── common/        # حراس + فلاتر
├── packages/
│   ├── types/                 # تعريفات الأنواع الموحدة
│   ├── constants/             # ثوابت الأعمال
│   └── utils/                 # 5 خوارزميات خاصة
├── docker/                    # إعدادات Nginx
├── deploy/                    # بيانات أولية init.sql
└── docker-compose.yml
```
